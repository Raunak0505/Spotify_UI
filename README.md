# Spotify UI Clone

## Overview
A pixel-accurate front-end clone of the Spotify web interface 
built using HTML and CSS, replicating the core layout and design.

## Tech Stack
- HTML
- CSS (Flexbox & Grid)

## Features
- Responsive layout design
- Navigation bar and sidebar
- Music player UI
- Spotify-inspired color scheme and typography
